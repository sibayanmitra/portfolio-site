Research

Evaluation Awareness Beyond English: Do LLMs Act Differently When Tested in Indic Languages?

T. Garg, S. Mitra, A. Karanjkar, A. Singh, J. S. Challa, Y. Sinha, S. Mehrotra, D. Kumar, P. Y. Maliya

arXiv preprint, 2026 / arXiv

Every model refused harmful requests more often when told it was being tested. In Indic languages the cue raised refusal by 14.4 points, up to English levels.

Tool-Error-Induced Next-Action Direction in Agentic LLMs

S. Mitra, with Claude Opus 4.7 and Sonnet 4.6 as AI co-authors

CAISc, 2026 / code

After a tool error, one direction predicts whether an agent retries, changes its arguments or gives up. Steering along it turns 94–100% of give-ups into retries.

The Number, Not the Values

S. Mitra

Project, 2026 / code

A re-test of the claim that a model's values bias its numeric estimates. It was mostly copying the number in the prompt: 19 of 20 answers when the question was broad, 0 of 20 when narrow.

Do Code LLMs Think in Python?

S. Mitra

Project, 2026 / code

Logit lens and probes on four code models, asking whether they route through Python the way multilingual models route through English. No clear evidence that they do.
